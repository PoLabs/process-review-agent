Process Review Agent

Checks every new formulation or process against the current safety, maintenance and QC documents, shows its sources, and leaves the decision to people.

What it does and who uses it

  • An intern submits a formulation. The agent flags each issue with a quoted passage from the source document and recommends a fix.
  • A second mode answers staff questions from the same documents.
  • Users: interns, supervisors who approve, EHS engineers. QC and maintenance own the documents.

What it depends on

  • Current, correct documents. It reads only the latest version of each.
  • Replaced, draft and retired documents are ignored. A missing document is reported as missing, not guessed.
  • People must keep the document set loaded and up to date.

How we measure value

  • Issues flagged, by severity and by area (safety, maintenance, QC). Recorded now.
  • Flags a supervisor accepts or rejects. To set up.
  • Reviewer time per submission and issues caught before approval. To set up.
  • No baseline exists yet for flags caught today or reviews per week.

  • Tamper-evident log of every step. Tests were written by the build team, with no outside set yet.

Safety and regulations

  • Human approval is required. The agent only recommends.
  • Free-text notes are screened for prompt injection. Submitters are pseudonymized. No personal data is written to disk.
  • Supports (not certified for): OSHA PSM and HazCom, EPA RMP, management of change, ISO 9001 and cGMP-style QC records.
  • Regulatory staff should confirm this mapping before external use.

What it takes at face value

  • Quantities, units and temperatures exactly as typed.
  • Equipment condition, only as recorded in the maintenance documents.
  • That the documents are accurate and complete.
  • No live plant data, sensors or physical inspection. Chemistry outside the documents is not judged.
  • Approver identity is typed in, not verified.

Cost

  • Per review: about 15,300 tokens in and 2,600 out, over about 5 model calls. Per question: about 2,200 in and 140 out. Dollar cost is not recorded, so multiply by current model prices.
  • Infrastructure: one small web service, a simple user interface and a Redis cache, run with Docker. No database of personal data.
