Source: averages of 48 full reviews in runs/20261123-120116-process-review-eval-006e12/trace.jsonl and 54 questions in …-process-qa-eval-c4710c.

How the numbers were derived. A saved test run (the 48 complete reviews among 51; 3 incomplete forms make no model calls) logs input and output tokens for every call. Averages: planning 941 in and 266 out; safety 3,218 and 526; maintenance 2,382 and 189; QC 2,227 and 396. The report step ran 59 times for 48 reviews, so 1.2 calls per review on average because the wording check sent 11 reports back once. Summed per review: about 15,300 tokens in and 2,600 out, which is about 18,000 in total. To turn this into dollars, multiply by current per-token prices for each model size, which are not stored in the repository. The kit’s note of about 2 cents per case per repeat is for a different agent (patient triage), so it is not used here. A cheaper model profile exists in the code but has not been tested for accuracy. Document search uses an optional embedding service; without its key, search falls back to keyword matching. Its cost is not recorded. The largest real cost is likely people time: two sign-offs for critical reports.
