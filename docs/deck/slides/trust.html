HOW YOU CAN TRUST AND VERIFY IT

Every flag shows its source, and the checks that matter are code, not AI judgment

Quoted sources

Each flag names the document, its version and the exact quoted sentence, so you can read the source yourself.

Hazard rules in code

Dangerous mixes, over-limit values and over-rated or out-of-service equipment are flagged by fixed rules. No AI output can remove or soften them.

A verify step

A claim whose quote or number is not in a current document becomes “unverified: check by hand”. It is never silently dropped.

Repeated testing

Tests that can fail

Record and people

A tamper-evident log lists every step, document and approver. People approve the exact report they saw.
