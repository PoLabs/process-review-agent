HOW IT WORKS

Code checks, AI reads and writes, people decide

1

Submit

Intern types the form or uploads a document. The agent drafts the form; the intern confirms every field.

PERSON + AI

2

Hazard rules

Fixed rules check dangerous mixes, temperature and concentration limits, and equipment ratings.

CODE

3

Look up

Searches only the current safety, maintenance and QC documents for passages about this process.

CODE

4

Review

Three AI reviewers, one per area, flag issues. Each flag needs a quoted passage.

AI

5

Verify

Drops any claim whose quote is not in a current document. Items with no document become flags.

CODE

6

Report

Looks for conflicts across areas, then writes a summary and a recommendation. Code checks the wording.

AI + CODE

7

Sign-off

Supervisor approves the exact report. An EHS engineer also approves if any flag is critical.

PERSON

An incomplete form goes back to the intern and no review runs.

Source: flows/process_review/GRAPH.md and README section 3. Top bar colour: teal = code, amber = AI, dark = person.

Walk through the seven steps. Teal bar = plain code that behaves the same way every time. Amber = an AI model reads or writes. Dark = a person. Steps 2 and 5 are the safety net: the hazard rules and the verify step are code, not AI judgment. A review normally makes five AI calls: one to plan searches, three area reviews, one to write the report. A sixth happens if the report wording check sends it back once.
